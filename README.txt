ギャル単語 Ver.5 🎀

追加機能：連続学習日数、ハートの学習カレンダー、累計GOODで上がるギャルランク、3種類のカード着せ替え。

GitHub の gyaru-tango リポジトリ直下に、このフォルダの5つのファイルをアップロードし同名ファイルを上書きしてください。ZIPそのものやフォルダごとはアップロードしないでください。

Ver.4と同じ localStorage キー gyaru-tango-v2 を使用します。学習日数は完了したテストの履歴を使って集計します。連続記録は昨日まで学習済みなら途切れずに表示します。累計GOODは完了テストのGOOD判定の合計で、同じ単語の再学習も含みます。

バックアップJSONのversionは5で着せ替え設定も含みます。Ver.4のバックアップからも復元できます。

データは端末内に保存されます。アップデート前にVer.4でバックアップを書き出して保管してください。
