ギャル単語 🎀（スマホ対応ウェブアプリ）

内容: 教科別単語帳、単語の登録と削除、表裏フリップ、順番／ランダム／逆向きテスト、上/下スワイプ、ハートのアニメーション、苦手の集計と再挑戦、ブラウザ内の自動保存。

使い方:
1. index.html をブラウザで開いて試せます（一部ブラウザでは保存やPWA機能に制約があります）。
2. スマホのホーム画面に追加してアプリのように使うには、このフォルダー全体を HTTPS の静的サイト（GitHub Pages / Netlify 等）に公開してください。
3. 公開した URL をスマホで開き、iPhoneならSafariの共有メニューから「ホーム画面に追加」、AndroidならChromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選択してください。
4. 単語はその端末・ブラウザの localStorage に保存されます。端末をまたいだ同期・クラウドバックアップは未実装で、ブラウザデータを消すと失われます。
5. Googleフォントの丸文字は初回読み込み時にネット接続が必要です。オフラインでは代替の丸ゴシックになります。

これはネイティブのApp Store/Google Play配信アプリではなく、インストール対応のPWAです。ストア配信には追加開発と審査が必要です。
