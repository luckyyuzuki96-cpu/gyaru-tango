ギャル単語 Ver.4 🎀

更新方法：このフォルダ内の index.html / icon.svg / manifest.webmanifest / sw.js / README.txt を、GitHubの gyaru-tango リポジトリ直下にアップロードして既存ファイルを更新します。

新機能：単語編集・削除、JSONバックアップと復元、教科別の学習履歴、判定直後／終了時の取り消し。

Ver.3 の単語データは既存の localStorage キー gyaru-tango-v2 を継続利用して引き継ぎます。アップデート前に重要な内容は控えてください。
学習履歴はVer.4以降の完了テストから記録します。保存は端末内のみです。

重要：ZIPファイルそのものではなく5つのファイルをリポジトリのルートにアップロードしてください。
